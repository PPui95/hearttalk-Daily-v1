# HeartTalk - ข้อความถึงเธอในวันนี้ 💛

เว็บให้กำลังใจ 999 ข้อความ 50-60 ตัวอักษร ไม่มีเสียง AI

Live: https://hearttalkui2-4fixes.netlify.app/

## Features
- UI เดิม 100% กล่องโค้ดลด HEART199 เหมือนเดิม
- เพิ่ม Login เล็กๆ มุมบนขวา (จำ Pro ข้ามเครื่อง)
- แก้ตัวอักษรตัด 50-60 ตัวแสดงครบ 2-3 บรรทัดแล้ว
- ต้นกล้า 0 ชม. คิดตามจริง, ตัด Free badge, ภาพรวมคิดตามจริง, ป่าเล็กๆ ย้ายขึ้นบน
